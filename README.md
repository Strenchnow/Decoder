# Decoder — Quick Convert

Альт+Клик по медиафайлу в Проводнике Windows открывает **круговое (radial) меню**
на PySide6 — выбери формат, файл конвертируется через ffmpeg рядом с оригиналом.

## Стек
- Python 3.10+
- PySide6 — круговое меню, иконка в трее
- pynput — глобальный хук Alt + Левый клик
- pywin32 — COM-объект Проводника (`Shell.Application`)
- ffmpeg — конвертация в фоне (`CREATE_NO_WINDOW`, не мигает консоль)

## Установка зависимостей

```powershell
python -m pip install PySide6 pynput pywin32

# ffmpeg должен быть в PATH
winget install Gyan.FFmpeg
```

## Запуск

### Видимый режим (для отладки)
```powershell
python main.py
```

### Фоновый режим (без окна консоли) — основной способ
```powershell
Start-Process pythonw.exe -ArgumentList "D:\Decoder\main.py"
```
Или ярлык в `shell:startup` на `pythonw.exe D:\Decoder\main.py` для автозапуска.

## Как пользоваться

1. Запустите `pythonw main.py` — в трее появится иконка ▶.
2. Откройте Проводник, выделите медиафайл.
3. **Зажмите Alt и щёлкните левой кнопкой** — появится круговое меню под курсором.
4. Выберите формат (клик по сектору) — начнётся конвертация.
5. Windows-toast уведомит о завершении. Результат — **рядом с исходником**;
   при том же формате выход получает суффикс `_converted`.

### Меню
| Действие | Результат |
|----------|-----------|
| Клик по сектору | Конвертация в выбранный формат |
| `Esc` / правый клик / клик мимо | Отменить меню |
| Клик по трою → Пауза | Временно отключить хоткей |
| Клик по трою → Перезапуск | Переподключить хук мыши/клавиатуры |
| Клик по трою → Выход | Остановить приложение |

## Поддерживаемые форматы

| Исходник | Доступные цели |
|----------|----------------|
| Видео (mp4, avi, mkv, webm, mov) | MP4, AVI, WEBM, GIF, MKV |
| Изображения (png, jpg, webp, ico, bmp, heic, heif) | PNG, JPG, WEBP, ICO, BMP, TIFF, GIF, HEIC |

## Троблшутинг

- **Меню не появляется** — проверьте, что активное окно — Проводник и вы
  удерживаете Alt во время клика.
- **«ffmpeg не установлен»** — `winget install Gyan.FFmpeg`, затем перезапустите
  приложение через трей → «Перезапуск».
- **Толкание/висание** — нажмите правой кнопкой по иконке трея → Перезапуск.

## Удаление

1. ПКМ по иконке трея → **Выход**.
2. Удалить ярлык из `shell:startup` (если настроен).
3. Удалить папку Decoder.
